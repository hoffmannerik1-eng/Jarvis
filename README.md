# Xtree

Minimalistischer KI-Chat mit schwarzem Hintergrund und blauem Chatfenster.

## Funktionen
- Responsive Oberfläche für PC, iPad und Smartphone
- Mehrere OpenRouter- und Gemini-API-Schlüssel mit automatischem Fallback bei Fehlern
- Optionaler lokaler Ollama-Zugriff (Browser-CORS beachten)
- Datei- und Bildanhänge, Spracheingabe
- Google- und Bildersuche
- Chatverlauf und Einstellungen lokal im Browser

## Start
GitHub Pages kann direkt die Datei `index.html` aus dem Repository-Root ausliefern.

API-Schlüssel werden ausschließlich im localStorage des verwendeten Browsers gespeichert. Füge niemals private Schlüssel in GitHub-Dateien ein.
